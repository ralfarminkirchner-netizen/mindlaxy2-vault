# Öffentliche Systemkarte

Die öffentlichen Repositories bilden Ausschnitte aus Wissens- und Herkunftsräumen, TiSCH, FASKA, MOONFiNGERS/SEiN, Integritätsinstrumenten, Kreativwelten, Spielen sowie Musik-/Sprachwerkzeugen ab.

Die Karte behauptet keinen einzigen kanonischen Kern. Jede Anwendung bleibt eine eigene Quelle oder Projektion mit eigener Grenze.
